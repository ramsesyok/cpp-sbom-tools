# v0.1.0

C/C++製品の部品収集、台帳作成、CycloneDX SBOM変換を行う初回リリースです。

## 配布物

- Linux amd64、Linux arm64、Windows amd64 向けのZIPを各1件
- 各ZIPに `cpp_deps`、`cpp_sbom`、それぞれのCycloneDX SBOM、手順書PDF、MITの `LICENSE`、`THIRD_PARTY_LICENSES.txt`、`SHA256SUMS` を同梱
- `cpp_deps --version` と `cpp_sbom --version` は `v0.1.0` を表示
- Go 1.27.3 でビルド

## 主な機能

- C/C++ビルドのヘッダ、リンクしたライブラリ、成果物から部品候補を収集
- Windows納入構成のOS、機器全体の登録アプリ、更新プログラムをGoから読み取り、システム製品の台帳入力を作成
- 部品台帳の作成と確認、CycloneDX SBOMへの変換

利用手順と対象範囲は同梱の `sbom-procedure.pdf` を参照してください。Windowsのビルド収集はMSVCが対象です。脆弱性照合には別途Grypeと脆弱性DBが必要です。Windowsバイナリのコード署名は行っていません。
